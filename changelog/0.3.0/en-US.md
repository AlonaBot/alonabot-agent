# alonabot-agent 0.3.0 - 2026-11-23

### Changed

- Rename the configuration Schema file to `plugin_config_schema.json` to match Core v0.3.0 ([#8](https://github.com/AlonaBot/alonabot-agent/pull/8)).
- Persona, MCP, skill, memory and user task pages show skeletons while loading and drop extra padding; counts and pagination are hidden when everything fits on one page ([#9](https://github.com/AlonaBot/alonabot-agent/pull/9)).
- If you use an older Agent, disable it before moving to Core v0.3.0. Then update Agent to this release and enable it. Your settings, secrets and data are kept.
