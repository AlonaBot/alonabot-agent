# alonabot-agent 0.4.0-dev.0 - Unreleased

### Added

- 新增 `send_message` 富消息发送与 `get_message_format` 按需格式发现，支持声明的平台扩展、合并转发和可见标签选项按钮。
- 新增本轮附件复用和管理员确认后的本地文件上传；发送策略为 allow 时仍须确认后读取文件。

### Changed

- 交互与定时对话按正文、富消息、后续正文的顺序投递，历史保留有序文字摘要与完整发送回执。
- 富消息在平台投递前拒绝 `BeforeSend` 改链，回执保留原始 `parts` 下标，历史保留 rejected 结果及错误。
- 定时正文按目标当前出站描述分块。该功能需要提供出站描述、消息预检、必确认与原始片段下标接口的 Core SDK。
