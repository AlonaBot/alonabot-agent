# AlonaBot 官方 Agent

[English](README.md)

支持模型、人设、工具及引用和转发图片输入的对话 Agent。

## 快速使用

使用 Core v0.3.0 或更高版本，在运行 Core 的机器上执行：

```fish
alonabot install --source AlonaBot/alonabot-agent --yes
```

配置 Provider 与聊天模型后，发送 `/ask 你好`。
